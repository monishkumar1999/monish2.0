Logarithms
-----------
logarithms is cut the problem half 

Logarithms help us understand "cutting the problem in half" repeatedly.

O(log n) algorithms are much faster than O(n) algorithms.

Binary Search is a classic example of O(log n)

O(n) (Linear Search) → Checking every word one by one.

O(log n) (Binary Search) → Open the book in the middle, see if the word is before or after, and repeat.
